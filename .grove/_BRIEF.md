# herdr — brief

## Goal

Sync the Linkuistics Herdr fork with upstream, release it through its Homebrew
formula, and upgrade the local install, preserving the fork's patches.

## Done when

The synchronized fork and formula are published, validation is recorded, and
the local binary reports the new fork version. Check the human's report of
two recent terminal lines disappearing on space switches after an agent exits.

## Decomposition

`plan-k1` executes this maintenance directly while it remains bounded.

## Pointers

- `FORK.md` owns fork maintenance, validation, release, and install instructions.
